   ↓

Phone call மூலம் victim-ஐ manipulate பண்ணுவது.

4. Smishing

SMS/message மூலம் malicious link அல்லது fake request அனுப்புவது.

🛡️ Phishing — 4 Prevention Recommendations

Exactly 4 recommendations கொடு:

Security awareness training
Multi-Factor Authentication (MFA)
Email filtering / anti-phishing controls
Verify suspicious requests independently

Example:

Employees should verify unusual payment or credential requests using a trusted communication channel instead of replying directly to the suspicious message.

3️⃣ Pretexting
Definition

Pretexting என்றால் attacker ஒரு fake story/scenario create பண்ணி victim-கிட்ட information அல்லது access வாங்குவது.

Example:

Attacker pretends to be an IT support employee and asks the victim for their password or verification code.

🔄 How attacker builds a false scenario

இதைக் step-by-step explain பண்ணு:

1. Gather information
       ↓
2. Create believable identity
       ↓
3. Create fake situation
       ↓
4. Contact victim
       ↓
5. Build trust
       ↓
6. Request sensitive information/action

Psychological levers:

Trust
Urgency
Fear

🛡️ Pretexting — 3 Prevention Measures
Identity verification
Employee security awareness training
Least privilege + strong access controls

Particularly:

Never provide passwords, MFA codes, or sensitive information based only on a phone call, email, or chat request.

5️⃣ Quid Pro Quo ⭐ Bonus

இதையும் add பண்ணு because checklist says bonus.

Meaning:

"Something in return"

Attacker victim-க்கு benefit/service offer பண்ணி information/access வாங்குவான்.

Example:

"I'm from IT support. I'll fix your computer, but first install this remote-support application."

Victim thinks:

Help / Benefit
     ↓
Information / Access
🛡️ Quid Pro Quo Prevention

2–3 points enough:

Verify support personnel identity.
Use only organization-approved support tools.
Never install software based on unsolicited requests.
